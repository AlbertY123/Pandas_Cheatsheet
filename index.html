7) Outliers (IQR, quantiles, clipping)

copy
# IQR rule
x = df["amount"].dropna()
q1, q3 = x.quantile([0.25, 0.75])
iqr = q3 - q1
lo, hi = q1 - 1.5*iqr, q3 + 1.5*iqr

outliers = df[(df["amount"] < lo) | (df["amount"] > hi)]

# Clip (winsorise)
df["amount_clip"] = df["amount"].clip(lo, hi)

# Quantile clip (simple + common)
lo2, hi2 = df["amount"].quantile([0.01, 0.99])
df["amount"] = df["amount"].clip(lo2, hi2)
WhenDo
Keep rows but reduce effectclip()
Remove extreme rowsdf[df[col].between(lo, hi)]
Visualise outliersdf.boxplot(column=col)

In exams: justify your choice (drop vs clip) based on whether outliers are errors or real rare events.

17) Data cleaning cookbook (high‑yield patterns)

Think like QA: clean → validate → re-check. Most marks come from writing checks + explaining decisions.
ProblemBest pattern
Sentinel values ("-", "?", "nil")df.replace({"-": pd.NA, "?": pd.NA})
Whitespace/case issuess.astype("string").str.strip().str.lower()
Invalid categoriesdf.loc[~df[col].isin(valid), col] = pd.NA
Range constraintsdf[col] = df[col].where(df[col].between(lo, hi))
Unit conversiondf["kg"] = df["g"] / 1000
Standardise columnsdf.rename(columns=lambda c: ...)
copy
# 1) Standardise columns + obvious missing/sentinels
COL_FIX = lambda c: c.strip().lower().replace(" ", "_")
df = df.rename(columns=COL_FIX)

sentinels = {"-": pd.NA, "?": pd.NA, "nil": pd.NA, "none": pd.NA, "": pd.NA}
df = df.replace(sentinels)

# 2) Strip + normalise key text fields
for c in ["city", "state", "email"]:
    if c in df.columns:
        df[c] = df[c].astype("string").str.strip()

# 3) Parse types safely
if "date" in df.columns:
    df["date"] = pd.to_datetime(df["date"], errors="coerce")
if "price" in df.columns:
    df["price"] = pd.to_numeric(df["price"], errors="coerce")

# 4) Validate expectations (fail fast)
expected = {"id", "date"}
missing_cols = expected - set(df.columns)
assert not missing_cols, f"Missing columns: {missing_cols}"
assert df["id"].notna().all(), "id contains missing"

# 5) Apply rule-based cleaning
valid_state = {"vic","nsw","qld","sa","wa","tas","act","nt"}
if "state" in df.columns:
    df["state"] = df["state"].astype("string").str.lower().str.strip()
    df.loc[~df["state"].isin(valid_state), "state"] = pd.NA

# Range check example: age 0..120
if "age" in df.columns:
    df["age"] = pd.to_numeric(df["age"], errors="coerce")
    df["age"] = df["age"].where(df["age"].between(0, 120))

19) Performance & memory (when data is big)

Rule: prefer vectorised ops over apply. Use categories. Read only what you need.
NeedUse
Read subset of columnsusecols=[...]
Chunked readpd.read_csv(..., chunksize=100_000)
Reduce memoryastype("category"), convert_dtypes()
Fast conditionalnp.where(cond, a, b)
Fast string ops.str (vectorised), avoid Python loops
copy
# Read efficiently
cols = ["id", "date", "state", "sales"]
df = pd.read_csv("file.csv", usecols=cols, parse_dates=["date"])

# Convert to memory-friendly dtypes
df["state"] = df["state"].astype("category")
df = df.convert_dtypes()

# Vectorised conditional
# if sales > 0 => 'pos' else 'nonpos'
df["sales_sign"] = np.where(df["sales"] > 0, "pos", "nonpos")

# Chunk processing example
out = []
for chunk in pd.read_csv("big.csv", chunksize=200_000):
    chunk["price"] = pd.to_numeric(chunk["price"], errors="coerce")
    out.append(chunk.groupby("dept")["price"].mean())
result = pd.concat(out, axis=1).mean(axis=1)
